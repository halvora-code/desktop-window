Desktop Homepage

What it is: This project is a replica of my pc screen but built with html and css JavaScript. You can click on different apps on the taskbar and it even shows real life time on a clock.

Some challenges I faced: I faced a lot of challenged with centering things on differnt places of the screen. So I learned a lot of x and y and the ratio of pixels on a web page. Making the first clock was not as 
bad as making the seconds one so I learned something from there. 

What I learned: I learned how to make better web design and color contrast. I feel more confident in scaling and placing. I learned how to make a clock using JavaScript and how to connect links to different pages.
